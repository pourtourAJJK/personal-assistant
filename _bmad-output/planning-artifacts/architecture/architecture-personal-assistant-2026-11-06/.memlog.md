- (decision) Working mode: Fast path; deliverable: spine + additional human-readable doc (architecture explainer for course evaluator)
- (constraint) Inherited from PRD: Python 3 + JSON storage, 4 modules (main/cli/task_manager/storage), no web framework in V1
- (decision) AD-1: Layered architecture (presentation -> business logic -> data access). Dependency flows downward only. Prevents CLI coupling with storage, enables future web migration.
- (decision) AD-2: Task is the sole domain entity. Shape: {id, title, category, due_date, completed, created_at}. Defined in task_manager.py. Prevents duplicate entity definitions across modules.
- (decision) AD-3: storage.py owns all JSON I/O. No other module touches data/tasks.json directly. Prevents divergent read/write paths and corruption.
- (decision) AD-4: Write-through persistence — every mutation (add/complete/delete) saves to JSON immediately. Prevents data loss on crash, no buffered writes.
- (decision) AD-5: Task ID generation: max(existing IDs) + 1, TASK + 3-digit zero-padded. Never reused after deletion. Prevents ID collision and stale references.
- (decision) AD-6: Error handling boundary: storage.py raises exceptions, task_manager.py catches and returns result tuples, cli.py presents user messages. Prevents error leakage to user-facing layer.
- (version) Python 3.8+ (standard library only: json, os, datetime). No external dependencies.
- (decision) Deferred: task editing, search/filter, category management, web migration, testing framework choice, packaging. All deferred to V1.1+ or per-story decisions.
- (decision) Rev-2 after dual review: AD-6 message ownership split — task_manager owns operation-result strings, cli owns prompts/re-prompts; closes contradiction with conventions table.
- (decision) Rev-2: AD-3 now defines load_tasks missing-file/empty-file semantics (return []), lazy init on first save, atomic write via temp file + os.replace, UTF-8 encoding; AD-4 bans module-level task cache — every op loads fresh; AD-7 (new): corruption = non-empty file failing json.loads or non-array root, all ops fail closed and never save_tasks on corrupt file; Interface Contracts section pins all task_manager signatures and result tuple shapes; Stack bumped to Python 3.9+ (PEP 585 annotations); created_at pinned to strftime without microseconds; ID overflow beyond TASK999 allowed (min-3-digit padding).
- (decision) Deliverable 2: ARCHITECTURE-EXPLAINER.html produced (Chinese, self-contained, for course evaluator). Covers layering diagram, AD-1..7 summaries, pinned interface contracts, FR/NFR mapping table, deferred rationale. Precedence rule: spine wins over explainer on conflict.
